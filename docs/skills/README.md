# Skill Catalog

Living inventory of installed Hermes skills and plugin-provided skills on the MRDTech Hermes host.

## Evidence policy

- **confirmed-session** = backed by retained Hermes session history in this build/install trail.
- **confirmed-session+frontmatter** = backed by retained session history plus repo-style metadata preserved in the installed skill.
- **inferred-family** = source repo inferred from a known skill family, but no preserved install-write record is available.
- **inferred-name-match** = source repo strongly suggested by the skill name/path, but no preserved install-write record is available.
- **path-only** = skill is on disk locally, but retained history does not prove its upstream source.
- **filesystem-derived** install date = taken from the current `SKILL.md` modification time, not a confirmed install event.
